일별 표

Claude Code는 오래된 대화 기록 파일을 자동으로 지웁니다(기본 30일). 이 앱은 불러온 집계를 브라우저에 따로 보관하므로, 가끔 「기록 새로 불러오기」를 눌러 두면 오래된 날짜도 계속 남아요.

예상 요금은 같은 사용량을 API로 썼다면 냈을 금액(2026년 11월 정가)이에요. Pro·Max 같은 구독 요금제는 월정액이라 실제 청구액과 다릅니다. 토큰 종류마다 단가가 달라서 사용량의 실제 무게를 비교하는 용도로 보세요. 캐시 읽기는 입력 단가의 2.5~10%, 캐시 쓰기는 125~200%로 계산합니다.
